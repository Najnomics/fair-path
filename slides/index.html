The idea

Price the swap by three facts

1. Who built the block
TEE / Flashtestations → 0.05%, no tax.

2. Where in the block
Flashblock slot 0–4 → 0.80% down to 0.075% if bonded.

3. Capital at risk
Unbonded public → 1.00% + 0.50% skim. Sandwich → slash 20% of bond.

Same liquidity. No dark pool. No wait. The price of now depends on fairness, slot, and bond.

How it works

beforeSwap prices · afterSwap recaptures

  • _classify — isFair → attested; else bonded → slot fee; else toxic.
  • _beforeSwap — return fee with OVERRIDE_FEE_FLAG.
  • _afterSwap — toxic: take / donate / settle. Bonded: same-block opposite swap slashes into donate.
  • v4 sender is the router. Searcher identity is 32-byte hookData.

Code — classification

src/FairPathHook.sol

function _classify(address searcher) ... {
    slot_ = flashblocks.slot();
    if (policy.isFair(block.number))
        return (Attested, ATTESTED_FEE, slot_);
    if (bonds.bondedOf(searcher) >= bonds.minBond())
        return (BondedSlot, _slotFee(slot_), slot_);
    return (Toxic, TOXIC_FEE, slot_);
}
